# Directory layout

Annotated tree of the monorepo. App-specific directories are under `apps/hyperframe/`.

```
motion-shorts/                 (monorepo root)
├── apps/
│   ├── hyperframe/                Vertical 9:16 shorts pipeline.
│       ├── src/
│       │   ├── lib/
│       │   │   ├── theme.css              CSS vars (colors, spacing). Single source of truth.
│       │   │   ├── easings.css            cubic-bezier vars compatible with GSAP.
│       │   │   ├── timeline-helpers.js    counter, staggerIn, fitText. Loads AFTER gsap.min.js.
│       │   │   └── captions-karaoke.js    TikTok-style karaoke. Loads AFTER timeline-helpers.
│       │   └── episodes/
│       │       └── <slug>/
│       │           ├── index.html           Monolithic single-file (CSS + HTML + GSAP + captions JSON inline).
│       │           ├── meta.json
│       │           ├── hyperframes.json
│       │           ├── lib -> ../../lib     Symlink for theme/easings/helpers/captions.
│       │           └── assets/
│       │               ├── voice.mp3        Generated by `bun run audio`.
│       │               ├── captions.json    Hyperframes-shape: [{text, start, end, confidence?}].
│       │               └── generated/        Optional generated PNG/WebP source assets for visual-heavy scenes.
│       ├── scripts/

│       ├── examples/                Script .txt files (input to `bun run audio`).
│       ├── public/voice/<slug>/     Canonical per-episode audio assets (mp3 + captions.json). Gitignored.
│       ├── samples/                 Voice library samples for picking presets. Gitignored.
│       ├── out/                     Auxiliary CLI working copies. Gitignored.
│       ├── renders/                 Local render cache from `--keep-local`. Gitignored.

│   │   │   └── __tests__/           vitest specs.
│   │   ├── package.json             @cgaravitoq/audio (private, in-source: main/types/exports -> ./src/index.ts).
│   │   └── tsconfig.json            extends ../../tsconfig.json.
│   └── catalog/                     Visual component catalog contract.
│       ├── manifest.json            Generated component manifest; inspect before authoring.
│       ├── components/<id>/entry.json  Source entries grouped into the manifest.
│       ├── snippets/                Copy-paste HTML snippets referenced by the manifest.
│       └── scripts/                 `bun run catalog:list`, build, check, route.
├── docs/                            Cross-cutting documentation (rules, layout, decisions).
│   └── decisions/                   Historical design decisions (one file per decision).
├── .agents/skills/                  Canonical skill source (audio-pipeline, canonical-short, new-episode, produce-from-notion).
├── .claude/skills/                  Symlinks -> .agents/skills/<name>.
├── .codex/skills/                   Symlinks -> .agents/skills/<name>.
├── .opencode/skills/                Symlinks -> .agents/skills/<name>.
├── .mcp.json, .codex/config.toml, .opencode/opencode.json   Notion MCP (hosted, OAuth).

├── biome.json, bunfig.toml          Shared tool configs.
├── tsconfig.json                    Base TS config (no `include`, `noEmit: true`).

├── package.json                     workspaces: ["apps/*","packages/*"], scripts delegate via turbo.

```

> **Sub-comps deprecated.** Production shorts use ZERO `data-composition-src`.
> The runtime force-applies `position: absolute; top:0; left:0; 100%x100%` on
> tracked stage children, which collapses sub-comp internal flex layouts.
> Monolithic single-file is the only supported pattern.

## Key paths summary

| Path | Description | Git |
|------|-------------|-----|
| `apps/hyperframe/src/episodes/<slug>/index.html` | Monolithic episode source | committed |
| `apps/hyperframe/src/episodes/<slug>/meta.json` | Episode metadata (tail, brand, dimensions) | committed |
| `apps/hyperframe/src/episodes/<slug>/assets/voice.mp3` | Voiceover (hydrate from R2 when remote-only) | committed only for local/source episodes |
| `apps/hyperframe/src/episodes/<slug>/assets/captions.json` | Word-level captions (hydrate from R2 when remote-only) | committed only for local/source episodes |
| `apps/hyperframe/src/episodes/<slug>/assets/generated/` | Generated raster source assets used by monolithic episode HTML | committed when required for reproducible render |
| `apps/hyperframe/public/voice/<slug>/` | Canonical audio assets | gitignored (regenerable) |
| `apps/hyperframe/renders/` | Local render cache when using `--keep-local` | gitignored |
| `apps/hyperframe/out/` | Working copies for render | gitignored |
| `.env` | API keys | gitignored |

## Catalog paths

Use `packages/catalog/manifest.json` as the source of truth for reusable visuals. From `apps/hyperframe/`, run `bun run catalog:list` to inspect available IDs, statuses, snippet paths, and source demos before touching `apps/hyperframe/src/episodes/<slug>/index.html`. Remote agents can use MCP `list_visual_components` to query the same catalog.

## Remote artifacts

R2 plus `render.remote.json` / `assets.remote.json` manifests are the canonical persistence layer for generated render and media artifacts. After verified upload, local render outputs are deleted by default; pass `--keep-local` only when you need a local mp4 to inspect. Fresh clones of episodes whose assets live only in R2 should run `bun run hydrate:episode <slug>` from `apps/hyperframe/` before previewing or rendering. Gateway transport (`R2_UPLOAD_GATEWAY_URL` + `R2_UPLOAD_GATEWAY_TOKEN`) is sufficient for both upload and hydration; direct-S3 write keys are an alternative.
